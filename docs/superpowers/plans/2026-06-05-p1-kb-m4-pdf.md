# KB-M4:PDF 深度解析实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 自研 PDF→markdown 解析(版面启发式:字号标题/页眉页脚去重/表格转 markdown 表),打通 .pdf 上传全链路;**验收 = 同一套 16 例 golden 在 PDF 解析语料上重跑,与 md 基线的 recall/MRR 差值即"解析损耗"**——深度文档理解派(RAGFlow DeepDoc)在赌什么,用数字回答。

**语料策略:** 用 reportlab 把虚构星辉人寿三篇渲染成 PDF(刻意埋陷阱:每页页眉"星辉人寿保险股份有限公司"+页脚页码、轻症给付表格、多页跨页),生成脚本与 PDF 产物都入仓(确定性)。零版权风险。真实公开 PDF 留作手动演示,不进 golden。

**底层选型:** 解析用 pdfplumber(字符级坐标+表格提取,但版面理解全部自研);生成用 reportlab(纯 Python,无系统依赖)。两者均为"无学习收益的轮子"豁免区——版面启发式才是学习核心。
